🚀 Getting Started

Renamr makes it easy to rename multiple files at once. Here's how to get started:

📁 Step 1: Select Files

Drag and drop a folder containing the files you want to rename into the Source Directory area, or click to browse and select a folder.

⚙️ Step 2: Choose Options

Set your file extension filter, choose sequential renaming, and configure your base name and numbering options.

▶️ Step 3: Start Renaming

Click "Start Renaming" to batch rename all your files according to your settings. It's that simple!

Rename in Place vs. Copy to New Location: By default, "Rename in place" is checked, which modifies your original files. Uncheck this option to create renamed copies in a new location while leaving your originals untouched - perfect for testing or when you want to keep backups.
Pro Tip: For time lapse photography, use sequential renaming with 4-digit padding (Frame_0001, Frame_0002, etc.) to ensure proper frame ordering in video editing software.

❓ Frequently Asked Questions

What file types does Renamr support? +

Renamr supports all file types including:

  • Images: JPG, PNG, RAW, TIFF, GIF, BMP, HEIC
  • Videos: MP4, MOV, AVI, MKV, FLV
  • Documents: PDF, DOC, TXT, RTF
  • Other: Any file type - just specify the extension or leave blank for all files

You can filter by specific extensions or rename all files regardless of type.

How do I rename files for time lapse photography? +

For time lapse sequences, follow these steps:

  • Enable "Rename Files Sequentially"
  • Set a descriptive base name like "Frame" or "Timelapse"
  • Use 4-digit number padding for proper sorting
  • Start from 1 (or your preferred starting number)
  • Ensure all your image files have the same extension
Example result: Frame_0001.jpg Frame_0002.jpg Frame_0003.jpg ... Frame_9999.jpg

This ensures your frames import correctly into video editing software like Final Cut Pro, Premiere, or DaVinci Resolve.

What's the difference between the rename patterns? +

Renamr offers three powerful renaming patterns:

  • Sequential (Pattern): Uses your base name + underscore + sequential numbers (Photo_001, Photo_002, etc.)
  • Date & Time: Names files based on creation/modification date and time
  • Random: Generates unique random names for anonymization

Sequential is perfect for photo series and time lapse. Date & Time is great for organizing by when files were created.

What does "Rename in place" mean? +

The "Rename in place" option controls where your renamed files go:

  • Checked (default): Files are renamed directly in their original location - your original files are modified
  • Unchecked: Renamed copies are created in a new location while your original files remain untouched
Recommendation: Uncheck "Rename in place" when testing rename patterns or when you want to keep your original files as backups.
How do I handle different file extensions in one folder? +

You have several options:

  • All files: Leave the File Extension field empty to rename all files
  • Specific type: Enter an extension like ".jpg" to rename only JPG files
  • Multiple runs: Run Renamr multiple times with different extensions

The app preserves original file extensions, so a .jpg file will remain .jpg after renaming.

What does "Number Padding" mean? +

Number padding adds leading zeros to keep consistent file name lengths:

  • 1 digit: Photo_1, Photo_2, Photo_3, ..., Photo_9, Photo_10, Photo_11
  • 2 digits: Photo_01, Photo_02, Photo_03, ..., Photo_99, Photo_100
  • 3 digits: Photo_001, Photo_002, Photo_003, ..., Photo_999, Photo_1000
  • 4 digits: Photo_0001, Photo_0002, Photo_0003, ..., Photo_9999, Photo_10000

For time lapse and large photo collections, 4-digit padding is recommended for proper sorting.

🔧 Troubleshooting

The app says "No files found" when I drag a folder +

This usually happens when:

  • The folder is empty
  • No files match your file extension filter
  • Files are in subfolders (Renamr only processes the main folder)

Solutions:

  • Check that the folder contains files
  • Try leaving the File Extension field empty
  • Move files from subfolders to the main folder
Renaming is very slow or the app becomes unresponsive +

For very large batches (1000+ files), the process may take time:

  • Close other applications to free up memory
  • Consider breaking large batches into smaller groups
  • Ensure your Mac has sufficient free disk space
  • Try restarting Renamr if it becomes unresponsive
Files are not sorting correctly after renaming +

This is usually a number padding issue:

  • Without padding: File_1, File_10, File_2 (incorrect order)
  • With padding: File_01, File_02, File_10 (correct order)

Use appropriate number padding based on your total file count:

  • Up to 99 files: 2-digit padding
  • Up to 999 files: 3-digit padding
  • Up to 9999 files: 4-digit padding
Getting permission errors when trying to rename +

Permission errors can occur if:

  • Files are currently open in another application
  • The folder is write-protected
  • Files are on a network drive with restrictions

Solutions:

  • Close any applications that might be using the files
  • Check folder permissions in Finder
  • Copy files to your local drive before renaming
  • Run Renamr with administrator privileges if needed
